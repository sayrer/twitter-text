# twitter_text_parser

The [Pest](https://pest.rs) PEG grammar that [twitter-text](https://crates.io/crates/twitter-text) uses to recognize URLs, @mentions, #hashtags, $cashtags, and emoji in tweet text. Most users want the `twitter-text` crate; this crate is the grammar it depends on.

Part of [twitter-text in Rust](https://github.com/sayrer/twitter-text).
